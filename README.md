# Рыбные места

Учебный Android MVP на Kotlin. Срок демонстрации: **5 ноября 2026 года**.

Приложение сохраняет личные рыболовные точки на телефоне: карта → долгое нажатие → форма → сохранение → метка → карточка. Есть редактирование, удаление с подтверждением, избранное и список для доступа к записям без интернета. Геолокация запрашивается только по кнопке.

## Открытие в Android Studio

1. Распакуйте весь проект. В Android Studio выберите **Open** и папку `FishPlaces`, содержащую `settings.gradle.kts`.
2. Используйте Android Studio Meerkat 2024.3.1 или новее с поддержкой AGP 8.9.2. Для Gradle выберите JDK 17 или 21: Settings → Build, Execution, Deployment → Build Tools → Gradle.
3. В SDK Manager установите **Android SDK Platform 35**, **Build Tools 35.0.0**, **Platform Tools**. Studio создаст `local.properties` с путём к SDK. Этот файл зависит от компьютера и не входит в архив.
4. Дождитесь Gradle Sync. Для первой синхронизации нужен интернет и доступ к Google Maven, Maven Central и Gradle Plugin Portal.
5. Подключите телефон с Android 6.0+ (API 23+) через USB, включите отладку по USB и подтвердите доверие компьютеру. Или создайте эмулятор с OpenGL ES 2.0.
6. Выберите конфигурацию **app** и нажмите **Run**. API-ключи, сервер и аккаунт не нужны.

Приложение использует нативный рендерер MapLibre. На эмуляторе необходимо работающее аппаратное/программное ускорение графики. Для защиты предпочтителен физический телефон.

## Сборка из терминала

Укажите путь к SDK в `local.properties` (`sdk.dir=...`) или переменной `ANDROID_HOME`. Команды из корня проекта:

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest lintDebug
./gradlew connectedDebugAndroidTest  # только с подключённым устройством/эмулятором
```

Windows: используйте `gradlew.bat` вместо `./gradlew`. Gradle Wrapper входит в проект; системная установка Gradle не нужна. Используется Gradle 8.11.1 с SHA-256 дистрибутива. При первом запуске тестов Robolectric дополнительно скачивает тестовый образ Android из Maven Central.

Результат сборки: `app/build/outputs/apk/debug/app-debug.apk`. Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`. Если на телефоне уже стоит сборка с другой подписью, обновление невозможно; перед удалением приложения сохраните нужные сведения вручную, поскольку удаление очищает базу.

## Как пользоваться

- На карте удерживайте нужную точку. Название обязательно; пробелы не считаются названием.
- Рыбу и заметку можно не заполнять. Оценка выбирается из 1–5 или «Без оценки».
- После сохранения нажмите на метку. Коричневая метка — избранное, зелёная — обычное место.
- В карточке доступны избранное, редактирование, удаление и переход к точке на карте.
- Вкладка «Список» показывает локальные записи и открывает те же карточки. Фильтры действуют и на карту, и на список.
- «Моё местоположение» просит разрешение и перемещает карту к найденной позиции. При отказе или тайм-ауте можно продолжить вручную. По умолчанию карта открывается на Новосибирске.

## Структура и архитектура

```text
app/src/main/java/ru/fishplaces/
  MainActivity.kt                 запуск Compose и создание ViewModel
  FishingApplication.kt           единственная база, репозиторий, HTTP-кеш карты
  data/FishingSpot.kt              модель Room и чистые правила валидации
  data/SpotDatabase.kt             RoomDatabase и DAO
  data/SpotRepository.kt           проверки и операции с DAO
  ui/SpotsViewModel.kt             StateFlow, coroutines, состояние формы и операций
  ui/FishPlacesApp.kt              карта/список, форма, карточка, подтверждение удаления
  map/FishingMap.kt                MapLibre в AndroidView, метки и жизненный цикл
  location/CurrentLocation.kt      одноразовое определение координат
app/schemas/                      экспортированная схема Room
app/src/test/                     JVM-тесты валидации, ViewModel и Room/SQLite через Robolectric
app/src/androidTest/              тест Room на устройстве
docs/                             защита, чек-лист, источники и отчёт проверок
```

Поток данных: **Compose → ViewModel → репозиторий → DAO → Room**. `Flow` Room передаёт изменения во `StateFlow` ViewModel; Compose наблюдает его через `collectAsStateWithLifecycle`. После записи карта и список получают новое состояние без перезапуска. Создание объектов вручную, без DI-фреймворка.

Все записи — таблица `fishing_spots`. Автоматический `Long id` отличает места даже с одинаковыми именами. `biteRating: Int?` хранит отсутствие оценки как `NULL`. Время `createdAt` хранится в миллисекундах Unix и сохраняется при редактировании. `category` всегда `fishing`; охота и грибы не реализованы. Подробнее: [материалы для защиты](docs/DEFENSE.md).

## Карта и ограничения MVP

osmdroid архивирован. Выбрана стабильная MapLibre Native 12.3.1 с растровым источником OpenStreetMap. Причины и официальные источники: [DEPENDENCIES.md](docs/DEPENDENCIES.md).

- Это **не офлайн-карта**. Без интернета тайлы могут отсутствовать; записи и их координаты остаются в Room и в списке. HTTP-кеш ускоряет повторный просмотр, но не гарантирует покрытие.
- На карте постоянно видна ссылка © Участники OpenStreetMap. Передаётся User-Agent `FishPlacesCoursework/1.0 (Android; ru.fishplaces)`, HTTP-кеш учитывает заголовки сервера. Prefetch дополнительных уровней отключён; массовой загрузки и офлайн-пакетов нет.
- Публичный сервер OSM не даёт SLA. Для массового распространения приложения необходимо оценить нагрузку и выбрать подходящего поставщика тайлов. Для учебного MVP — только обычный интерактивный просмотр.
- Данные хранятся на одном телефоне. Удаление приложения или очистка его данных удаляет места. Резервное облачное копирование отключено; экспорта и синхронизации нет.
- Разрешения геолокации только foreground, без фонового сервиса. Поиск ограничен 15 секундами. Геолокация не используется для отслеживания и не записывается автоматически.
- ViewModel сохраняет форму при повороте экрана. При принудительном завершении процесса несохранённая форма может потеряться; сохранённые записи остаются в Room.
- Версия БД — 1. Разрушительные миграции не используются. При изменении схемы нужно увеличить версию, добавить `Migration` и проверить её тестом.
- Тёмная тема, фотографии, погода, сервер, авторизация, чаты, реклама, оплата и уведомления не входят в MVP.
