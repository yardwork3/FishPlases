# Чек-лист проверки на телефоне

Дата: __________ Устройство/Android: __________ Проверяющий: __________

Отмечайте пункты только после фактического выполнения. Этот список сам по себе не является отчётом о выполнении.

## Установка и карта

- [ ] Установить debug APK, запустить: открывается Новосибирск, видны карта и атрибуция.
- [ ] Прокрутить и масштабировать карту двумя пальцами, проверить читаемость подсказок.
- [ ] Нажать атрибуцию: открывается страница авторства OpenStreetMap.
- [ ] Пустой список предлагает открыть карту; пустое избранное объясняет, как его заполнить.

## Сквозной сценарий

- [ ] Удерживать точку, заполнить «Заводь у моста», рыба «Окунь, щука», оценка 4, заметка «Подход со стороны тропы».
- [ ] Сохранить: появляется метка; нажать её, сверить все поля и координаты.
- [ ] Сверить ту же запись в списке.
- [ ] Полностью закрыть приложение, открыть снова: запись и метка сохранились.
- [ ] Принудительно остановить приложение через настройки/`adb shell am force-stop ru.fishplaces`, открыть: запись сохранилась.

## Форма

- [ ] Пустое название и название из пробелов не сохраняются, видна ошибка.
- [ ] Название с пробелами по краям сохраняется с обрезанными краями.
- [ ] Оставить рыбу, оценку и заметку пустыми: место сохраняется; карточка показывает отсутствие сведений.
- [ ] Выбрать 1, затем 5, затем «Без оценки»: сохранённое значение соответствует выбору.
- [ ] Быстро несколько раз нажать «Сохранить»: создаётся одна запись.
- [ ] Повернуть телефон с заполненной формой: значения сохранены.
- [ ] На маленьком экране и с клавиатурой прокрутить форму; сохранение и отмена доступны.
- [ ] Нажать «Отмена» и системную кнопку «Назад»: запись не создаётся.

## Изменения

- [ ] Открыть редактирование: все поля заполнены, координаты и время добавления прежние.
- [ ] Изменить название и заметку: обновляются карточка, метка и список, второй записи нет.
- [ ] Включить избранное в карточке: меняется цвет метки, запись видна в фильтре «Избранные».
- [ ] Выключить избранное в фильтре избранных: запись исчезает из фильтра, остаётся во «Всех».
- [ ] В форме новой записи включить избранное: после сохранения фильтр его показывает.
- [ ] Нажать «Показать на карте» из карточки списка: карта центрируется на точке.
- [ ] Удалить → «Отмена»: запись остаётся.
- [ ] Удалить → «Удалить»: исчезают запись и метка; после перезапуска запись не возвращается.

## Геолокация и сеть

- [ ] При первом запуске диалог разрешения не появляется автоматически.
- [ ] Нажать «Моё местоположение», отказать: понятно сообщение, приложение работает.
- [ ] Повторить после окончательного отказа: нет падения, можно продолжить вручную.
- [ ] Разрешить приблизительную геолокацию (Android 12+): приложение не требует обязательно точную.
- [ ] Разрешить геолокацию и дождаться позиции: карта перемещается.
- [ ] Выключить геолокацию: сообщение о недоступности, приложение не зависает.
- [ ] Уйти с экрана/повернуть телефон при поиске позиции: нет падения.
- [ ] Отключить интернет, открыть новый район: тайлы могут отсутствовать; приложение не обещает офлайн-карту.
- [ ] Без интернета открыть список, карточку, изменить заметку/избранное, перезапустить: изменения сохраняются.
- [ ] Без интернета долго нажать на карту: форма открывается, запись можно сохранить с координатами.
- [ ] Включить интернет: просмотр карты снова работает.
