# Firebase

1. Создайте проект Firebase и Android-приложение с package name `ru.fishplaces`.
2. Скачайте `google-services.json` в `app/google-services.json`.
3. В Authentication включите провайдер Email/Password.
4. Создайте Cloud Firestore и опубликуйте правила из `firestore.rules`.
5. Выполните синхронизацию Gradle и пересоберите приложение.

Без конфигурации доступны unit-тесты и lint; приложение показывает инструкцию настройки.
Firebase сохраняет сессию. Firestore использует постоянный дисковый кеш и очередь записей.
Сообщение о сохранении означает постановку в локальную очередь, а не подтверждение сервера.
При отказе сервера появляется ошибка списка; используйте повторную загрузку.

Точки находятся в `users/{uid}/spots/{id}`. Числовой ID модели преобразуется в строку
имени документа без изменения существующих полей Room. Для новых точек используется
положительная случайная 63-битная часть UUID.

При выходе уничтожается отдельный ViewModelStore аккаунта вместе с корутинами и
Compose-состоянием (карточки, диалоги, форма, карта). Старую базу Room приложение
не удаляет и автоматически в облако не загружает.

Офлайн доступны ранее загруженные точки; первый вход и регистрация требуют сети.
Кеш Firestore общий на установку, но запросы и правила изолированы по UID.
