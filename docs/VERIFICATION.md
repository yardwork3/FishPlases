Чистые JVM-тесты проверяют пробельное название, диапазон оценки, необязательную оценку, координаты и категорию. Тесты ViewModel проверяют десять быстрых нажатий «Сохранить», обрезку пробелов, недопустимые данные, сохранение формы при ошибке и успешную повторную попытку, редактирование, избранное, фильтрацию и удаление.

`RoomStorageTest` работает с настоящей Room/SQLite в Robolectric (Android API 28, native SQLite). Он создаёт файл БД, сохраняет запись без оценки, редактирует её, включает избранное, закрывает и заново открывает БД, проверяет сведения и сохранность id/createdAt, удаляет запись и ещё раз открывает БД. Этот тест подтверждает хранение данных, но не проверяет рендеринг карты и разрешения телефона.

Предупреждения lint относятся к доступности более новых версий библиотек (`GradleDependency`). Набор версий намеренно зафиксирован и успешно собирается с SDK 35. Полный отчёт: [lint-debug.txt](reports/lint-debug.txt). Результаты тестов: [HTML](reports/unit-tests/index.html) и XML в `reports/junit/`.

## Особенности облачной среды

SDK и полный JDK были установлены в `/workspace/tools`, поскольку изначально SDK отсутствовал, а доступная системная Java была JRE. Служебные каталоги Gradle/Android перенаправлены в доступную для записи папку. Для Robolectric использован локальный Gradle init-script, задающий `user.home` только JVM тестового процесса: системный домашний каталог среды доступен лишь для чтения. Сетевые запросы выполнялись через прокси среды с проверкой TLS. Эти настройки среды не включены в переносимый проект и не нужны на обычном ПК с доступным для записи домашним каталогом.

Общая проверенная команда: `./gradlew assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest --no-daemon --max-workers=2` с указанными настройками среды. Дополнительно выполнено `./gradlew lintDebug --rerun-tasks`.

## Не проверено на устройстве

Физический телефон не подключён, готового эмулятора нет; `/dev/kvm` отсутствует. Попытка запуска ADB также остановилась на недоступном для записи `/home/agent/.android`. Поэтому **приложение не запускалось на телефоне или эмуляторе**, а `connectedDebugAndroidTest` не выполнялся.

Не подтверждены визуально: загрузка тайлов на Android, жесты и нажатия на метки, работа клавиатуры и системных отступов, системный диалог разрешения и отказ в геолокации, поворот Activity, перезапуск приложения целиком. Для этих проверок подготовлен [ручной чек-лист](MANUAL_TESTS.md). Их нужно выполнить на телефоне перед защитой.
